# GA Checkpoint — new marine storefront

**[Скачать новую версию ZIP](https://github.com/mamedaliewramil-eng/GAconcept/raw/refs/heads/main/ga-checkpoint-new.zip)** · [HTML](ga-checkpoint-new.html) · [Полный макет](new-preview-full.png) · [Мобильный экран](new-preview-mobile.png) · [Эффект прокрутки](new-preview-scroll.png)

Распакуйте ZIP и откройте `ga-checkpoint-new.html` в браузере. Изображения, стили, шрифт и JavaScript встроены: для просмотра и работы демонстрационного каталога интернет не нужен. Если скачивание не начинается, откройте ZIP в репозитории и нажмите **Download raw file**.

Полностью новая реализация HTML, CSS и JavaScript с Attitude как ориентиром по оформлению. Предыдущий GA HTML, его структура, данные каталога и скрипты не использовались.

- Первый экран заполнен фотографией от левой до правой границы окна. Три изображения плавно меняются каждые 15 секунд; есть ручное переключение и пауза.
- Сразу ниже расположен ряд из шести товаров с узкими боковыми отступами. При прокрутке товарный блок поднимается поверх нижней части большого баннера, а карточки последовательно выезжают снизу вверх; ход появления связан с прокруткой.
- Затем идёт невысокий фотографический баннер на всю ширину и второй ряд из шести товаров.
- На телефоне товарные ряды листаются горизонтально.
- Работают поиск, сортировка, фильтры по категории и цене, избранное, карточки товаров, количество и корзина.
- Кнопки плоские и контрастные; иконки и стрелки выполнены в едином тонком контурном стиле.

Товары, цены, характеристики и сгенерированные изображения демонстрационные. Просмотр корзины не оформляет заказ и не принимает платёж. Избранное и корзина хранятся в этом браузере. При настройке уменьшенного движения автосмена первоначально приостановлена; её можно включить вручную.

Проверено в Chromium: 28 групп сценариев, включая интервал карусели 14999/15000 мс, паузу и ручное управление, полноширинные изображения, два ряда товаров, закрепление баннера и ход подъёма карточек при прокрутке, сохранение корзины и избранного. Горизонтального переполнения страницы нет на ширинах 360, 390, 768 и 1440 пикселей. Внешних сетевых запросов у самостоятельного HTML нет.

Редактируемые исходники, изображения и инструкция сборки: [new-store](new-store/). Шрифт Archivo распространяется по SIL Open Font License, см. [лицензию](new-store/FONT-LICENSE.txt).
