# GA Checkpoint — Attitude-inspired redesign

**[Скачать готовый ZIP](https://github.com/mamedaliewramil-eng/GAconcept/raw/refs/heads/main/ga-checkpoint-attitude.zip)** · [HTML на GitHub](ga-checkpoint-attitude.html) · [Превью для компьютера](preview-desktop.png) · [Превью для телефона](preview-mobile.png)

Распакуйте ZIP и откройте HTML в браузере. Если GitHub не начинает скачивание автоматически, откройте файл `ga-checkpoint-attitude.zip` в репозитории и нажмите **Download raw file**.

Откройте `ga-checkpoint-attitude.html` в браузере. Установка зависимостей не нужна.

Обновлены первый экран, типографика, шапка, категории, карточки каталога, информационные блоки и подвал. Макет адаптирован под мобильные экраны; доступны светлая и тёмная темы.

Файл содержит изображения первого экрана и категорий и шрифт Barlow Condensed. Эти новые изображения сгенерированы как фотореалистичные иллюстрации и не представляют конкретные товарные модели. Лицензия шрифта находится в `FONT-LICENSE.txt`.

Ссылки на фотографии отдельных товаров сохранены из исходника: для них нужен интернет. Если снимок недоступен, показывается заглушка. Демонстрационный каталог, цены, хранение данных в браузере и функции аккаунта/корзины перенесены из исходного HTML; серверная обработка заказов и сообщений этим файлом не добавляется.

Это адаптация визуального направления Attitude. Во вложении референса сохранена оболочка Shopify Theme Store без встроенного демо и папки ресурсов, поэтому точное совпадение с темой по этому вложению проверить нельзя.

Проверено в Chromium: поиск, сортировка, фильтры, избранное, карточка товара, выбор опций и добавление в корзину, аккаунт, проверка заказа, панель поддержки, смена темы и мобильное меню. Проверено отсутствие горизонтального переполнения на ширинах 390, 768, 1024 и 1440 пикселей.
